📂 Como carregar todos os desenhos automaticamente

O site busca imagens na pasta ./desenhos/ (ao lado deste arquivo HTML) de 4 formas:

1. Via arquivo lista.json (Infalível): Abra o terminal do VS Code na pasta do projeto e rode o comando PowerShell abaixo para listar todos os arquivos automaticamente: 

dir desenhos -Name | ConvertTo-Json | Out-File -Encoding utf8 desenhos/lista.json

2. Live Server: Ao abrir com Open with Live Server, a pasta é lida sozinha.
3. Nomes numerados: Salve como 1.jpg, 2.png... até 50.
4. Lista manual: Edite LISTA_DESENHOS no início do <script>.
